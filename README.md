# SRM Piksel v2.0 Pro

Premium turn-based **pixel roguelike** — timing combat, class evolution, pets, bloodline meta.

## Struktur folder

```
srm-piksel/
├── index.html
├── README.md
└── assets/
    ├── classes/     warrior, thief, mage, fist, bard, archer
    ├── races/       8 race portraits
    ├── pets/        slime, wolf, sprite, imp, owl
    ├── bosses/      forest_guardian, dungeon_lord, shadow_king, void_dragon
    ├── items/       20+ item icons (weapons, armor, rings, potions…)
    └── ui/          hub_banner, title_banner
```

## Fitur Pro

- **Aset per role** — sprite terpisah, bukan satu sheet
- **Lobi Castle** — portrait hero animasi float, banner, stat pills
- **Animasi** — fadeUp, popIn, floaty, pulse-glow, shake hit, shimmer title
- **Shop diperluas** — Void Saber, Dragon Scale, Mana Flask, Elixir, Scroll, Boots, Amulet…
- **Combat feedback** — shake + flash saat damage
- **Path cards** staggered animation

## Cara main

1. Extract ZIP utuh
2. Buka `index.html` (path `assets/` harus relatif)
3. Atau deploy folder ke GitHub Pages

## Kode

`SRM` · `PIKSEL` · `LINEAGE` · `BLOOD` · `PETS`

## Keyboard

`1` Attack · `2`/`3` Skill · `G` Guard · `M` Meditate · `P` Potion · Space timing
